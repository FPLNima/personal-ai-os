# Personal AI OS

A public, high-level write-up of a personal AI setup: Bob as chief of staff, plus a few specialists, with shared context in Notion.

You can take this and feed it to your own agent (for example Grok Bot, or any similar system) as a starting point for setting up your own team of agents. The details are in [docs/how-my-bot-setup-works.md](docs/how-my-bot-setup-works.md).

## Why this exists

This repo is a testbed for learning how AI agents, coding assistants, and connected tools can become a practical operating system.

It stays at the level of setup, notes, and examples. Personal data does not belong here.

## Themes

- A small team of specialist agents around a chief-of-staff setup
- Notion as a shared context layer for those agents
- Attio is the source of truth for my personal CRM
- AI-native GTM workflows
- Agentic coding with Codex, Cursor, and similar tools
- Small personal apps and learning projects

## Status

Living public learning repo. Some work stays private, and some will become public once it is useful and safe to share.
